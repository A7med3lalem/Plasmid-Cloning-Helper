# Plasmid-Cloning-Helper
Given a plasmid FASTA (and optionally an insert FASTA) plus a small panel of common restriction enzymes, the tool reports where each enzyme cuts, flags enzymes that cut the vector exactly once, and flags enzymes that also cut inside your insert.

This is my first Project with many updates to come ultimately and helpfully leading to a tool that can take any fasta seqeunce and automate the cloning process in theory allowing a person to simply do it in lab
